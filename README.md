# Student Task Manager
 
A web application for managing academic tasks.
 
## Project Description
 
The Student Task Manager is a simple web-based application developed as a pair-based collaborative project to demonstrate Git and GitHub concepts in a real development workflow.
 
The application allows users to add, display, complete, delete, and search tasks.

## Git Workflow
 
1. Create the project and initialize Git
2. Create commits and push to GitHub
3. Create feature branches for each feature
4. Open Issues and Pull Requests
5. Review code and merge into `main`
6. Resolve merge conflicts
7. Create a version tag and GitHub Release
## Branches
 
| Branch               | Purpose                        |
| -------------------- | ------------------------------ |
| `main`               | Stable, final version          |
| `feature/task-form`  | Task input form                |
| `feature/task-style` | Application styling            |
| `feature/task-search`| Task search functionality      |

## How to Run
 
1. Clone the repository:
```
   git clone <repository-url>
```
2. Open the `student-task-manager` folder.
3. Open `index.html` in a web browser.
